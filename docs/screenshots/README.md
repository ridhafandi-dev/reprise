# Captures Reprise

Captures de l’application native 0.4.0 sur macOS, prises le 10 septembre 2026 via l’API de capture de fenêtre CUA. Les JPEG sont conservés tels que capturés, sans retouche de l’interface.

- `reprise-library.jpg` : Mes fils avec le post public « Experimenting with Blur & Gradients » de Hamad Tanveer (@uiux_hamad).
- `reprise-edge.jpg` : carte au bord droit avec le profil public de Vinz (@hivinz_).

La couleur du verre fumé dépend du contenu derrière le panneau. Le cadre de la capture du panneau inclut la zone transparente nécessaire à son animation.

Actualiser ces images lors d’un changement visible de l’interface et indiquer la version dans le README principal.
